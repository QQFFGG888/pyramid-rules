# 可复用区块模板

直接复制，按主题替换方括号内容。

## 区块 A1 文首元信息

六要素按序呈现。

```markdown
# [教程名称]

- 版本号：v1
- 撰写者：[署名；未提供时标注 AUTHOR]
- 总字数：约 [N] 字，定稿后统计回填
- 预计阅读时间：约 [M] 分钟，按总字数除以每分钟 400 字向上取整
- 主题简述：[1–2 句，说清这篇教程讲什么、读完能做什么]
```

## 区块 A2 本篇约定

置于元信息之后，3 至 5 行。

```markdown
**本篇约定**

- 受众：[只具备高中阶段通用基础知识的读者，无领域背景]
- 比喻系统：全文只用「[图书馆]」一个比喻。
- 覆盖范围：[是什么 / 怎么运作 / 最小上手]；不覆盖 [XX 选型、XX 调优]。
- 默认假设：[无领域前置知识；正文已交代全部所需背景]。
```

## 区块 B 三栏对照表

```markdown
| 生活说法 | 正式说法 | 一句话定义 |
| --- | --- | --- |
| [那座图书馆] | [知识库] | [存放供检索的资料的地方] |
| [把书找出来] | [检索（Retrieval——按问题找出相关资料）] | [一句话定义] |
```

## 区块 C 衔接句库

```markdown
- L1→L2：「这个 X，在技术文档里有个正式名字。」
- L2→L3：「名字记住了还不够，下面把机制说准。」
- L3→L4：「原理如此，动手验证。」
- 章间：「上一步你已经拿到了 [A]，现在用它来做 [B]。」
```

## 区块 D 前置准备块

用于 L4 本地命令之前。

```markdown
### 开始前需要准备什么

按顺序检查，缺哪一项补哪一项。

**1. [运行时]。** 检查命令：

```
[python --version]
```

应看到 `[3.14]`；不是就 `[换成 3.14 的解释器]`。

**2. [依赖包]。** 检查命令：

```
[python -c "import torch; print('ok')"]
```

缺哪个装哪个：

```
[pip install torch]
```

**准备确认**

- [ ] [运行时版本正确]
- [ ] [依赖包齐全]
```

## 区块 E 章末自检

每个概念章末使用，反问设问各取所需，每问附提示或回指，不直接给全答案。

```markdown
**章末自检**

1. [反问：把该章结论变成问题，读者答「是」即过关]？
2. 「[正式术语]」对应生活里的哪个动作？提示：回看 [1.2] 的表。
3. [机制层设问，指向 1.3 的因果链]？提示：[一句指引]。
4. [操作层设问，指向 1.4 的跑通判据]？提示：[一句指引]。
```

## 区块 F 术语速查表

文末使用，按编号汇总全篇术语。

```markdown
## [N] 术语速查表

| 编号 | 术语 | 通俗解释 | 技术解释 |
| --- | --- | --- | --- |
| 1 | [术语] | [生活说法] | [一句话精准定义] |
```

## 区块 G 常见困惑

文末使用。

```markdown
## [N+1] 常见困惑

**困惑 1：[现象/疑问]。**
[一句解答]。详见「[回指章节名]」。
```

## 区块 H 符号与冒号速记

符号从简，不用装饰性符号、emoji、花式分隔线。冒号提示的内容达到一句以上时另起一行。

```markdown
# 合规写法
检查命令：

```
python --version
```

# 不合规写法
检查命令：先在终端运行 python --version，确认版本不低于 3.10，再进行下一步。
```

## 区块 I 原文带（如有）

有阅读门槛的原文才设，没有就省略整块，不留空标题。解读型单元置于单元开头，教学型单元置于深读带之前。

```markdown
原文（[来源；无来源时写「原文未提供」]）：

> [逐字原文。公式与代码用代码块。术语首现处紧接编号，如 检索[1]]

[紧随一句，说明这段原文在讲什么，与原文之间不插别的内容]
```

原文之后的顺序固定，先深读带，后通读带。

```markdown
[深读带：用词专业精简的技术解释]

[通读带：把上面的技术内容落回读者语言，可用比喻]
```

## 区块 J 名词锚

首现标号，写在术语首次出现处之后。

```markdown
检索[1]（Retrieval——按问题找出相关资料）是这一步的动作。
```

章末收口，附在章末自检之后，只列编号与术语名。

```markdown
**本章名词**：1 检索、2 知识库、3 生成
```

文末收口见区块 F 术语速查表。全篇编号连续，不按章重排。
