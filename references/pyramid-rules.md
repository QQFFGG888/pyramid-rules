# 四层金字塔逐层填充规则

四层金字塔是一个认知台阶序列：L1 建直觉 → L2 落名字 → L3 保准确 → L4 能动手。从 L1 建直觉逐层上，绝不跳层——跳层的代价是读者带着空白的或错误的心智模型硬啃术语。

## 全局原则

- **零熵增**：禁用新名词解释旧名词。每层引入的新词数 = 该层职责的最小值（L1 为 0，L2 为术语本身，L3 为必要机制词，L4 为配置项名）。
- **比喻锁定**：全篇一个比喻系统。检查法：grep 各层比喻关键词，出现第二比喻系统的意象即违规。
- **认知台阶**：每层只比上一层多「一级台阶」的信息。读者在任意一层停下，都应带走完整的一块理解。
- **自然引导**：概念与信息随讲解过程自然引出，不生硬抛出。术语不空降——生活场景先出现，正式名字后给出；新概念进入前先给一句「为什么需要它」。四层顺序本身就是自然引导的机制。
- **叙事弧线**：整篇走「落地（L1 生活场景）→ 升维（L2/L3 概念与机制）→ 发芽（L4 动手 + 常见困惑延伸）」。
- **预判困惑**：每章预判读者最可能的一个困惑并在章内解答；解决不了的集中到文末「常见困惑」。
- **领域安放**：「本篇约定」里一句话说明主题在领域地图中的位置，回答「我为什么要学这个」。

## L1 纯生活比喻

- **定位**：建立直觉。回答「它像什么、解决什么麻烦」，不回答「它叫什么」。
- **内容颗粒度**：一事一喻，一句一事实推进；一个概念 3–6 句。
- **语言四铁律**：
  1. **英文词锚定**：必须写成「中文锚点（英文——一句解释）」，如「检索（Retrieval——去库里把东西找出来）」。L1 允许的英文仅限此形式。
  2. **一句一事实**：一句话只讲一个点，不并列，不用复杂句式。
  3. **比喻锁定**：全篇一个比喻系统，禁止中途换喻。
  4. **主线唯一**：只讲主线，不埋支线伏笔。
- **衔接逻辑**：结尾一句把读者送上层，如「这个管图书馆的人，在技术文档里有个正式名字，下一节就给你」。
- **反面教材**：术语一次性塞入（「RAG 通过向量数据库做语义检索并 rerank」出现在 L1）；多比喻混用；只给结论不给推理。

## L2 比喻+术语双栏对照

- **定位**：把 L1 的直觉映射到正式术语。回答「它的正式名字是什么、和我刚才理解的对不对得上」。
- **内容颗粒度**：一张三栏表（生活说法 | 正式说法 | 一句话定义），每行一个术语，行数 = 概念涉及术语数（一般 3–6 行）；表前一句开场、表后一句校验。
- **格式规则**：比喻与术语一一对应；一个比喻对应多个术语时必须逐行区分说明。
- **衔接逻辑**：表后一句「你已经认识它了，只是之前叫法不同」，再指向 L3。
- **反面教材**：表里塞机制细节（属 L3）；用新术语解释旧术语（熵增）。

## L3 精简技术语言

- **定位**：准确表述。读者读完能把机制复述给同行听而不失真。
- **内容颗粒度**：一段一概念；每个核心概念覆盖 ≥5 个 5W2H 要素（是什么 / 为什么需要 / 解决什么 / 怎么运作 / 何时不用或局限）；比喻退场，因果链与结构保留。
- **语言规则**：允许密集术语，但每个术语必须在 L2 表出现过，或首次出现时给一句定义。因果链闭合：每个「所以」都往前找得到「因为」。
- **衔接逻辑**：回指 L2（「上表第 2 行的 X，在技术语境下是……」），再指向 L4（「原理如此，下面动手」）。
- **反面教材**：堆砌限定语导致句子失去主谓宾；把 L4 才需要的操作细节提前混入。

## L4 实操配置

- **定位**：能上手。读者照做能得到可验证的结果。
- **内容颗粒度**：步骤编号无歧义；命令、配置、代码逐字直给，复制即用；每个关键步骤后写「看到什么算对」。
- **格式规则**：本地命令前给前置准备块（每项：要求 + 检查命令 + 修复命令，模板见 `blocks.md` 区块 D）；辅助界面操作配截图，复杂流程可配流程图。
- **衔接逻辑**：全篇终点。章末接「章末自检」；延伸内容放文末「常见困惑」，不在 L4 内继续升维。
- **反面教材**：伪步骤（说「配置好环境后……」却不给配置命令）；编造版本号、路径或输出。

## 章末自检

每个概念章末固定放「章末自检」，用反问、设问做教学检验，帮助读者自查。写法：

- 3–5 个问题；不用「- [ ]」勾选框，直接编号提问。
- 问题类型：**反问**（把该章结论变成问题，读者心里答「是」即过关，如「RAG 是不是先查资料再回答？」）；**设问**（提问后附一句提示或回指，引导读者回原文核对，如「『检索』对应生活里的哪个动作？提示：回看 1.2 的表」）。
- 每问附一句提示或回指章节，不直接给全答案。
- 覆盖该章三个层次各至少一问：直觉层（L1 比喻）、术语层（L2 对照）、机制或操作层（L3/L4）。
- 模板见 `blocks.md` 区块 E；自检数须等于概念章数。

## 层间衔接句式

- L1→L2：「这个 X，在技术文档里有个正式名字。」
- L2→L3：「名字记住了还不够，下面把机制说准。」
- L3→L4：「原理如此，接下来动手验证。」
